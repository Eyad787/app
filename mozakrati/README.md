# مذاكرتي (Mozakrati) 📚

تطبيق بيساعد طالب الجامعة ينظّم دراسته: الجدول، المواد، الامتحانات والتسليمات، المهام، ومؤقت بومودورو للمذاكرة.
بيشتغل على **Android** و **iOS** و**المتصفح**، وتقدر تسطّبه على اللاب توب كـ **PWA** ويشتغل من غير إنترنت.

- **واجهة التطبيق بالإنجليزي** ومن الشمال لليمين (LTR)، والأسبوع الدراسي بيبدأ السبت.
- وضع فاتح وداكن تلقائي حسب جهازك.
- على الموبايل: شريط تحت وعمود واحد. على اللاب توب: قائمة جانبية وأعمدة متعددة، والجدول بيظهر الأسبوع كله.
- كل البيانات بتتحفظ على جهازك فوراً (من غير سيرفر)، وتقدر تعمل نسخة احتياطية (ملف JSON) من الإعدادات.

## اللي موجود دلوقتي (المرحلة 1 ✅)

| الشاشة | فيها إيه |
|---|---|
| **أول تشغيل** | الاسم، الكلية، الفرقة، الترم، نظام التقدير (GPA من 4 أو نسب وتقديرات)، وإضافة المواد بسرعة. تقدر تتخطّى أي خطوة وتكمّلها من الإعدادات. |
| **الرئيسية** | تحية باسمك وتاريخ النهارده، محاضرات النهارده بالترتيب مع تمييز الحالية والجاية، أقرب امتحان أو تسليم بعدّ تنازلي، مهام النهارده، وقت مذاكرتك النهارده من الهدف، وزرار «ابدأ مذاكرة». |
| **الجدول** | محاضرة / سكشن / معمل، اليوم، من كام لكام، المكان، الدكتور أو المعيد، مع تنبيه لو فيه تعارض في المواعيد. على الموبايل يوم يوم (واسحب يمين وشمال)، وعلى اللاب توب الأسبوع كله في جدول زمني. الجمعة اختيارية من الإعدادات. |
| **المواد** | كل مادة بلونها. صفحة المادة فيها: الدكتور، الساعات المعتمدة، مواعيدها، امتحاناتها، مهامها، ووقت المذاكرة الكلي ليها. |
| **الامتحانات والتسليمات** | ميدترم، فاينل، كويز، عملي، شفوي، Assignment، مشروع. عدّ تنازلي، ترتيب حسب الأقرب، **أحمر لو فاضل أقل من 3 أيام**، علامة «خلصت» للتسليمات، وتقسيم لـ «قادم» و«فات». |
| **المهام** | مرتبطة بمادة أو عامة، أولوية (عالية/متوسطة/منخفضة)، ميعاد اختياري. فلاتر: النهارده، الأسبوع ده، حسب المادة، المكتملة. علامة صح بأنيميشن، وإضافة سريعة بـ Enter. |
| **مؤقت المذاكرة** | تختار المادة، 25 دقيقة مذاكرة و 5 راحة، وبعد 4 جلسات راحة 15 دقيقة (كله بيتعدّل). تشغيل، إيقاف مؤقت، تخطّي، إنهاء. صوت واهتزاز وإشعار لما الجلسة تخلص. كل جلسة بتتسجل. **المؤقت بيعتمد على وقت النهاية مش على عدّاد**، فلو قفلت التطبيق أو راح في الخلفية بيفضل مظبوط، ولو الجلسة خلصت وهو مقفول بتتسجل أول ما تفتحه. |
| **الإعدادات** | بياناتك، نظام التقدير، أوقات البومودورو، الهدف اليومي، الصوت والاهتزاز، إظهار الجمعة، حد الغياب، تصدير واستيراد نسخة احتياطية، ومسح كل البيانات (بتأكيد مرتين). |

## 🌐 افتحه من المتصفح على طول

**https://eyad787.github.io/app/**

افتح الرابط من أي موبايل أو لاب توب، ومن غير ما تسطّب حاجة ولا تشغّل الكمبيوتر. وتقدر تسطّبه كتطبيق:
- **أندرويد (Chrome):** القائمة ⋮ ← «Add to Home screen» أو «Install app».
- **آيفون (Safari):** زرار المشاركة ← «Add to Home Screen».
- **اللاب توب (Chrome / Edge):** أيقونة التسطيب في آخر شريط العنوان.

بعد أول فتح بيشتغل من غير نت. بياناتك بتتخزن في المتصفح على الجهاز ده بس.

**تحديث النسخة اللي على الرابط** (بعد أي تعديل في الكود):
```bash
npm run build:pages
```
وبعدين ارفع محتوى فولدر `dist` على فرع `gh-pages`.

## أولاً: تشغيله على موبايلك بـ Expo Go

### 1. جهّز الكمبيوتر
1. نزّل **Node.js** نسخة LTS (20 أو أحدث) من https://nodejs.org
2. اتأكد إنه اتثبت: افتح الـ Terminal (أو Command Prompt في ويندوز) واكتب `node -v`

### 2. نزّل المشروع وثبّت المكتبات
```bash
git clone <رابط-المستودع>
cd app/mozakrati
npm install
```

### 3. ثبّت Expo Go على الموبايل
- **أندرويد:** من Google Play ابحث عن **Expo Go**.
- **آيفون:** من App Store ابحث عن **Expo Go**.

> التطبيق معمول على **Expo SDK 57**، فخلّي Expo Go على موبايلك آخر نسخة.

### 4. شغّله
```bash
npx expo start
```
- هيظهرلك **QR Code**. خلّي الموبايل والكمبيوتر على **نفس الواي فاي**.
- **أندرويد:** من Expo Go اضغط **Scan QR code**.
- **آيفون:** صوّر الكود بالكاميرا العادية وافتحه في Expo Go.

**لو الموبايل مش شايف الكمبيوتر** (شبكة الجامعة مثلاً): شغّل `npx expo start --tunnel`.
**لو الواجهة طلعت من اليمين للشمال (معكوسة):** اقفل Expo Go خالص من التطبيقات المفتوحة وافتحه تاني، إعداد الاتجاه بيتطبق مع أول فتح.

> ملحوظة: Expo Go بيظهر تحذير إن الـ push notifications مش مدعومة فيه. ده طبيعي، لأن التطبيق بيستخدم **إشعارات محلية** بس (زي إشعار انتهاء جلسة المذاكرة)، ودي شغّالة عادي.

## ثانياً: تشغيله على اللاب توب وتسطيبه كـ PWA

### للتجربة السريعة
```bash
npx expo start --web
```
هيفتح على `http://localhost:8081` في المتصفح.

### علشان تسطّبه وتشغّله من غير نت
وضع التطوير مش بيشغّل الـ offline. اعمل نسخة الإنتاج:
```bash
npm run build:web          # بيطلّع النسخة في فولدر dist
npx serve dist --single    # بيشغّلها على http://localhost:3000
```
بعد كده:
- **Chrome / Edge:** افتح الرابط، وهتلاقي أيقونة التسطيب (شاشة عليها سهم) في آخر شريط العنوان، أو من القائمة ⋮ ← «Install Mozakrati». هيبقى ليه أيقونة على سطح المكتب ويفتح في شباك لوحده.
- **Safari على الماك:** File ← Add to Dock.
- **على الموبايل (لو حابب تستخدم نسخة الويب):** Chrome ← «إضافة إلى الشاشة الرئيسية»، أو Safari ← زرار المشاركة ← «Add to Home Screen».

بعد أول فتح، التطبيق بيشتغل **من غير إنترنت** (عن طريق service worker).

**ترفعه على النت مجاناً؟** ارفع محتوى فولدر `dist` على Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages، وخلّي أي رابط مش موجود يرجع لـ `index.html` (SPA).

> بيانات نسخة الويب متخزنة في المتصفح نفسه (منفصلة عن الموبايل). علشان تنقل بياناتك بين الأجهزة استخدم **تصدير/استيراد** من الإعدادات، لحد ما المزامنة تيجي في المرحلة 4.

## ثالثاً: تعمل ملف APK بـ EAS Build

1. اعمل حساب مجاني على https://expo.dev
2. ثبّت أداة EAS وسجّل دخول:
   ```bash
   npm install -g eas-cli
   eas login
   ```
3. من جوه فولدر `mozakrati`:
   ```bash
   eas build:configure                       # أول مرة بس
   eas build -p android --profile preview
   ```
   بروفايل `preview` في `eas.json` متظبط إنه يطلّع **APK** تسطّبه على طول.
4. البناء بيتم على سيرفرات Expo (حوالي 10-20 دقيقة). في الآخر هيديك رابط و QR Code تنزّل منه الـ APK على موبايلك وتسطّبه (هيطلب منك تسمح بالتسطيب من مصادر غير معروفة).

> لو عايز ترفعه على Google Play: `eas build -p android --profile production` بيطلّع ملف AAB.
> للآيفون محتاج حساب Apple Developer: `eas build -p ios`.

### هيكل المشروع
```
app/                 الشاشات (Expo Router)
  (tabs)/            الشاشات الرئيسية: الرئيسية، الجدول، المواد، الامتحانات، المهام، المؤقت، الإعدادات
  onboarding.tsx     أول تشغيل
  subject/[id].tsx   صفحة المادة
  *-form.tsx         نماذج الإضافة والتعديل
components/          مكونات الواجهة (كروت، أزرار، منتقي التاريخ والساعة، جدول الأسبوع، شريط التنقل...)
constants/           الألوان، النصوص، أبعاد الشاشة، عناصر التنقل
hooks/               الثيم، حجم الشاشة، الوقت الحالي، متحكم البومودورو
lib/
  types.ts           أنواع البيانات
  db/                التخزين: AsyncStorage + التحقق من البيانات + النسخة الاحتياطية + DataProvider
  logic/             الحسابات كدوال نقية + __tests__
  notifications*.ts  الإشعارات (موبايل / ويب)
public/              ملفات الـ PWA: index.html، manifest.json، sw.js، الأيقونات
```

**ملاحظات تقنية:**
- التخزين بـ AsyncStorage (على الويب بيبقى localStorage)، وكل جزء من البيانات في مفتاح لوحده فأي تعديل بيتحفظ فوراً. اخترناه بدل expo-sqlite لأن sqlite على الويب محتاج إعدادات سيرفر خاصة (COOP/COEP) بتصعّب الـ PWA، وحجم بيانات الطالب صغير. لو احتجنا SQLite أو Supabase بعدين، التغيير هيبقى في `lib/db/storage.ts` بس.
- البيانات المتحمّلة أو المستوردة بتعدّي على `lib/db/validate.ts`: العنصر البايظ بيتشال والناقص بياخد قيمة افتراضية، فملف تالف مش هيوقع التطبيق.
- كل حاجة شغالة على **Expo Go** من غير native modules إضافية.
